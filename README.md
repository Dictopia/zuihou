# zuihou - A simple time signal bot for Discord
# これは何？
毎時00分になると指定したvcに時報を流すDiscord Botです。
同一サーバー内で複数のVCが登録されている場合、優先度（登録順）が高いVCから探索し、ユーザーがいるVCを順番に巡回して再生します。
複数サーバーに導入されている場合、毎時00分00秒に全サーバー同時に処理が開始されます。
# 使い方
以下のスラッシュコマンドで設定等を行います。
- /jh_info
現在の選択中キャラ、音量、通知チャンネル、登録VC（優先度順）を Embed で表示します。
- /jh_character
時報を再生するキャラクターを選択します（プルダウン形式）。
- /jh_volume
時報の再生音量を設定します（0.0 〜 1.0）。
- /jh_vc_add
指定したボイスチャンネルを巡回対象の末尾に追加します。
- /jh_vc_remove
指定したボイスチャンネルを巡回対象から除外します。
- /jh_set_text
エラーや切断通知を送信するテキストチャンネルを設定します。
- /jh_test
(デバッグ用)登録された全サーバーのVCで sample.mp3 を即時テスト再生します。
# 導入方法
## Token設定
.envの`YOUR_TOKEN_HERE`を自分のbot tokenに書き換えます。
## 音源について
著作権の都合上、音声ファイルおよびキャラクター別フォルダは含まれていません。
利用する際は、data/ ディレクトリ配下に以下のような構成でフォルダおよび mp3 ファイルを配置してください。
```
.
├── main.py
├── .env
└── data/
    ├── sample.mp3     # (必須)テスト用および音源欠損時の代替音源
    ├── Character1/    # キャラクターフォルダ（任意の名前）
    │   ├── 0000.mp3   # 00:00 の時報音源
    │   ├── 0100.mp3   # 01:00 の時報音源
    │   ├── ...
    │   └── 2300.mp3   # 23:00 の時報音源
    └── Character2/    # 複数キャラクター配置可能
        ├── 0000.mp3
        ├── 0100.mp3
        ├── ...
        └── 2300.mp3
```
## 動作要件
以下のバージョンを想定して開発しています。
- FFmpeg 8.0.1
- Python 3.10以上
## パッケージのインストール
```shell
# 任意のパッケージマネージャーでdiscord.py, dotenvを追加
pip install discord.py[voice] dotenv
# mp3再生用にffmpegをインストール
sudo apt install ffmpeg
```
## 実行方法
`main.py`を実行します。
